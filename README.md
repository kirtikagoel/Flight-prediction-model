# ✈️ Flight Price Prediction ML Project

This is a Machine Learning web app that predicts flight ticket prices based on:

- Airline
- Source
- Destination
- Number of Stops
- Duration

## 🧠 Tech Used
- Python
- Pandas
- Scikit-learn
- Flask
- HTML

## 🚀 How to Run

1. Clone the repository
2. Install requirements:
   pip install -r requirements.txt
3. Train the model:
   python train_model.py
4. Run the app:
   python app.py
5. Open browser at:
   http://127.0.0.1:5000

## 📌 Note
This is a demo ML project for learning purposes.
